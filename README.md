# langgraph-agentic-ai

Personal learning project exploring agentic AI patterns with [LangGraph](https://langchain-ai.github.io/langgraph/).

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and fill in your own API keys:

```bash
cp .env.example .env
```

## Notes

`.env` is gitignored — keep all keys out of version control.
